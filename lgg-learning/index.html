01Case

패턴으로 일기 쓰기 GPT

Suit · 외국어 학습 서비스 · 기획 · 제작 · 운영(1인)

회화책으로 패턴을 공부하면 표현은 머리로 이해할 수 있습니다. 그런데 그 패턴으로 직접 말하고 쓰는 연습은 학원이나 원어민 친구가 없으면 하기 어렵습니다. 「프랑스어 회화 핵심 패턴 233」으로 공부한 사람이 아웃풋 연습까지 혼자 복습할 수 있게 만든 커스텀 GPT입니다.

내가 본 것

밖에서 배운 지식을 나의 세계에서, 나의 언어로 응용해 보는 연습이 언어 공부에 아주 중요합니다. 그래서 연습할 소재는 학습자가 고르게 했습니다. 좋아하는 영화 속 인물이든, 자기 전공의 현장이든.

학습 흐름

Input교재로 패턴을 이해한다책에서 배운 패턴 · 어휘 · 문법
→
Output내가 고른 소재로 직접 써 본다이 GPT가 채우는 구간
  1. 01 · 학습자 → GPT요청: 패턴 범위 · 수준 · 주제를 주고 한국어판 일기를 받는다
  2. 02 · 학습자작문: 굵은 문장을 배운 패턴으로 직접 쓴다
  3. 03 · GPT교정: 틀린 곳과 이유를 확인하고 다음 범위로
  1. 01학습자 → GPT

    요청

    연습할 패턴의 범위와 수준, 일기 주제를 정해 일기를 요청합니다. GPT는 한국어판 일기를 쓰고, 패턴을 써서 옮길 문장을 굵게 표시합니다.

  2. 02학습자

    패턴으로 작문

    한국어판을 보고 굵은 문장을 배운 패턴으로 직접 프랑스어로 씁니다. 이 단계가 교재만으로는 할 수 없던 아웃풋 연습입니다.

  3. 03GPT

    교정

    작문한 일기를 GPT에게 보내 교정받습니다. 틀린 곳과 그 이유를 문장마다 확인합니다.

교정이 끝나면 다음 패턴 범위로 같은 흐름을 반복합니다. 일기 쓰기 챌린지에서는 이 흐름을 매일 이어 가도록 했습니다.

화면은 학습 흐름을 보여 주려고 다시 그린 예시입니다. 문장도 예시로 새로 썼습니다.

한 일

  • 1:1 수업에서 교재로 배운 패턴을 실제로 쓰는 연습이 비어 있다는 것을 확인하고, 그 구간을 채우는 것으로 툴의 목적을 정함
  • 학습자가 패턴 범위 · 수준 · 주제를 정해 요청하고, 한국어판을 보고 패턴으로 작문한 뒤 교정받는 3단계 학습 흐름 설계
  • 수업에서 학습자의 관심 분야로 연습시키던 방식을 툴로 옮김. 예를 들어 제과제빵을 전공한 학습자에게는 디저트 키친에서 동료와 나눌 법한 상황으로 연습하게 했던 방식
  • 블로그에 공개하고 일기 쓰기 챌린지로 실제 사용 방식을 지켜본 뒤, 효과가 좋았던 요청 방식을 정리해 다시 공유

구체적인 수식어 달기

패턴 22~28을 써서 B2 수준으로, 시니컬한 파리 택시 운전사의 웃긴 일기를 써 줘

일기 주제 추천받기

봉준호 감독이 시나리오를 어떻게 구상하는지 웹 검색을 하고, 패턴 43~49로 B2 수준의 하루 일기를 상상해서 써 줘

02Case

LLM 평가 연구

프랑스 경제부 디지털 규제 전문 센터(PEReN) · 2024.03 ~ 2024.08 · 석사 학위논문

온라인 콘텐츠의 혐오 표현을 LLM이 자동으로 가려내게 하는 연구. 어떤 프롬프트 전략이 어떤 모델에서 잘 작동하는지 재는 틀이 필요했습니다.

한 일

  • 최신 논문과 사례를 바탕으로 여러 프롬프트 전략을 설계하고 최적화
  • 여러 LLM의 혐오 표현 분류 성과를 정량 · 정성 방법으로 비교하는 평가 프레임워크 구축
  • 모델 응답이 지나치게 장황한 문제에는 LLM-judge 전략을 설계. 첫 모델의 분류 응답이 장황하면 두 번째 모델이 요약하고 다시 분류해, 정확하고 간결한 예측을 유도

평가 흐름

  1. 01프롬프트 전략 설계
  2. 02여러 LLM의 분류
  3. 03장황한 응답은 LLM-judge가 요약 · 재분류
  4. 04정량 · 정성 평가

실험 설계

프롬프트를 맥락 · 질문 · 판정어 · 답변 형식으로 나누고, 한 번에 한 부분만 바꿔 가며 성능을 쟀습니다. 맥락 3개와 질문 3개는 모든 조합을, 판정어는 25개를 영어 · 프랑스어로 시험했습니다.

문구를 조금 바꾸는 것은 성능에 거의 영향을 주지 않았습니다. 성능을 크게 바꾼 것은 프롬프트 전략(일반 프롬프트와 few-shot 프롬프트)이었습니다.

결과

이 연구로 석사 학위논문 「Hate Speech Detection with Prompting LLM」을 썼습니다. 데이터는 프랑스어, 논문은 영어입니다.

OpenAI API · Hugging Face · vLLM · Python

03Case

현업 주도 Agent 캠프

대기업 통신사 S사 · 5일 과정 · 과정 설계와 제안 리드

전사 AX 가속화를 위한 경쟁입찰. 가상 데스크톱(VDI) 환경이라 외부 도구를 쓸 수 없는 조건에서, 현업 구성원이 사내 플랫폼의 노코드 · 로우코드만으로 업무용 AI 에이전트 MVP를 5일 안에 직접 만드는 과정.

내가 본 것

만들고 싶은 것과 지금 만들 수 있는 것은 다릅니다. 그래서 자동화할 업무를 넓게 꺼낸 뒤, 「사내 툴 · 사내망 · 주어진 데이터로 지금 만들 수 있는가」로 좁혔습니다.

Idea to MVP 5단계

  1. 01발산기획
  2. 02학습
  3. 03수렴기획
  4. 04정의
  5. 05구현

에이전트를 만들기 전에 아이디어톤을 두고, 수렴기획에서 「지금 만들 수 있는가」로 과제를 좁힙니다.

한 일

  • Idea to MVP 5단계 방법론 정립
  • Agent 기획서 · 정의서 템플릿과, 산출물이 기준을 넘는지 가리는 평가 체계 설계
  • 5일 동안 현장에서 참여자의 이해도와 중간 결과물을 확인하고, 고객사 담당자의 피드백을 매일 과정에 반영
  • RFP 분석 · 입찰설명회 · 기술미팅 직접 리드

결과

1인 1 에이전트참여자 전원 구현
85~90%MVP 완성률
약 1.8배파일럿 성과로 입찰을 따내 이어진 후속 과정의 규모

내가 본 것
